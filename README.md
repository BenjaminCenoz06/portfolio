# Portfolio — Freelance Designer & Developer

Portfolio interactivo de alto impacto inspirado en el diseño de Maxime Veilleux / estilo Awwwards.

## 🚀 Características
- **Header & Navbar**: Logo geométrico con botón píldora animado interactivo.
- **Hero Section**: Retrato monocromático con iluminación dramática y textura de grano cinematográfico.
- **Insignia "Located in"**: Píldora fijada con globo terráqueo animado en rotación continua.
- **Marquee Gigante**: Ticker infinito con animación CSS fluida a lo ancho de la pantalla.
- **Drawer de Navegación**: Menú deslizable con enlaces y redes sociales.
- **Formulario "Quick hire"**: Modal interactivo para contacto rápido.

## 🛠️ Tecnologías
- HTML5 semántico
- CSS3 moderno (Variables CSS, Flexbox, Grid, Keyframes, Clamp)
- JavaScript Vanilla (Micro-interacciones, parallax, custom cursor)
- Tipografía Geist (Google Fonts)

## 💻 Ejecución local
Puedes abrir directamente el archivo `index.html` en cualquier navegador o usar un servidor local como Live Server.
